# 📦 StockVision — Dashboard de Controle de Estoque

Dashboard interativo desenvolvido em Python para acompanhar produtos, quantidades, valor do estoque e itens que precisam de reposição.

## Funcionalidades

- Indicadores gerais do estoque
- Filtro por categoria
- Identificação de produtos com estoque crítico
- Gráfico de quantidade por produto
- Gráfico de valor por categoria
- Visualização de entradas e saídas
- Tabela completa dos produtos
- Exportação do relatório filtrado em CSV

## Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- Plotly

## Como executar

1. Instale as bibliotecas:

   `pip install -r requirements.txt`

2. Execute o aplicativo:

   `streamlit run app.py`

## Objetivo

Projeto criado para praticar análise de dados e desenvolvimento de dashboards, demonstrando habilidades aplicáveis a estágios nas áreas de Python, dados e automação.
